Java Tournee Graph

Java application for creating, managing and visualising a tour using graph structures.

Overview

This project implements a Java application based on graph theory to represent and work with a tour.
The application uses a graphical interface to allow users to interact with the tour and visualise its graph structure.


What I worked on

Developing the application in Java
Representing the tour using graph structures
Implementing graph-based algorithms and operations
Creating a graphical user interface
Visualising graphs using GraphStream
Structuring the project using object-oriented programming
Working collaboratively with Git


Technologies

Java
GraphStream
